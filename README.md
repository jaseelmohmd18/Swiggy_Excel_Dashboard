# Swiggy_Excel_Dashboard

1. Project Title

Power BI Swiggy Sales Dashboard Project

2. Short Description / Purpose

This project walks through building a real-world Excel + Power BI sales dashboard step-by-step, guiding you from raw data to a finished interactive report. The focus is on transforming and visualizing sales data so users can analyze trends and performance comprehensively.

3. Tech Stack

-Microsoft Power BI Desktop

-Power Query (M Language) for data transformation

-DAX (Data Analysis Expressions) for metrics and KPIs

-Excel / CSV files as the primary data source

4. Data Source

The dashboard takes sales data exported from Excel or CSV files, typically representing real-world order and revenue records from a food delivery platform like Swiggy. You clean and prepare this data in Power BI before building interactive visuals.

5. Features / Highlights

-End-to-end design of a sales dashboard in Power BI

-Data loading, cleaning, and modeling using Power Query

-Key performance indicators (KPIs) like total sales, order count

-Interactive slicers for filtering by date, category, or region

-Trend charts and visual storytelling for performance analysis 

-Beautiful, user-friendly design for business insights
